# Build 19: ユーザーページ・フォロー・公開範囲画面

## やること

- ユーザーページ（`/users/:id`）を作る。名前、閲覧者が見られる投稿の一覧（無限スクロール）、フォロー／フォロー解除／申請／申請の取消のボタンと状態表示を出す
- 非公開ユーザーで閲覧権が無い場合は、名前とフォロー（申請）ボタンを出し、投稿が非公開であることを示す。自分自身にはフォローボタンを出さない。ゲストにはログインを促す。フォロー上限（5,000人）の到達時はその旨を表示する
- 公開範囲の設定画面（現在の設定の表示と「公開」「非公開」の切り替え）を作る
- 投稿カード・単体ページの投稿者名をユーザーページへのリンクにする（build-17, 18 の画面に足す）

## やらないこと

- フォロー申請の承認・拒否、フォロワー一覧の画面（build-20）
- 他ユーザーのフォロワー一覧・フォロー中一覧（スコープ外）

## 対応する受け入れ基準

- US-6.1, US-6.2, US-6.3, US-6.4, US-6.5, US-6.6, US-6.7, US-6.8, US-6.9, US-6.10, US-11.1

## 受け入れ基準

- [ ] 投稿者名からユーザーページに移動でき、名前と見られる投稿の一覧が新しい順に表示される
- [ ] フォロー・解除ができ、フォロー済みと分かる。自分自身にはボタンが出ない
- [ ] 非公開ユーザーにはフォロー申請になり、申請中と分かり、取り消せる
- [ ] 閲覧権が無い非公開ユーザーのページで、名前とボタンが表示され、投稿が非公開であると分かる
- [ ] フォロー上限に達するとその旨が表示される
- [ ] 公開範囲を切り替えられ、現在の設定が分かる
- [ ] ゲストはページを閲覧できるが、フォローを求めるとログインを促される
