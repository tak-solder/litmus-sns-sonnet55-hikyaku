# Build 08: フォロワー一覧・外すAPI

## やること

- `GET /me/followers`（自分のフォロワーを名前つきで、フォローの日時の新しい順に1回最大20件・複合カーソルで返す）
- `DELETE /me/followers/:userId`（フォロワーを外す。外された側は自分をフォローしていない状態になる）

## やらないこと

- 他ユーザーのフォロワー一覧・フォロー中一覧（スコープ外）
- フォロワー画面（build-20）

## 対応する受け入れ基準

- US-14.1, US-14.2, US-14.3, US-11.6

## 受け入れ基準

- [ ] 自分のフォロワーが名前つきで新しい順に返り、続きを取得できる
- [ ] フォロワーを外すと一覧から消え、そのユーザーからは自分が非公開のとき投稿が見えなくなる（可視性述語は build-09 で検証済みの前提）
- [ ] 外されたユーザーは、自分が非公開なら改めて申請でき、公開なら改めてフォローできる
- [ ] フォロワー自身がフォローを解除した場合も、同様に非公開の投稿が見えなくなる
