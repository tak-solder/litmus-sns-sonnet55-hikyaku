# Build 21: 検索画面

## やること

- 検索画面（`/search?q=`）を作る。ヘッダーの検索ボックスから遷移し、結果を投稿カードで新しい順に表示する（無限スクロール）
- 空・条件が成り立たない入力は検索せず、API が返す理由を表示する。0件のときは該当なしを表示する

## やらないこと

- ユーザー名検索、投稿者・期間での絞り込み（スコープ外）
- 検索構文の入力補助（スコープ外）

## 対応する受け入れ基準

- US-10.1, US-10.3, US-10.5, US-10.10

## 受け入れ基準

- [ ] キーワードを入力して検索でき、結果が新しい順に表示され、続きが自動で読み込まれる
- [ ] 空・除外だけなど成り立たない入力では、検索せずその旨が表示される
- [ ] 検索結果の投稿カードでいいねと単体ページへの遷移ができる
- [ ] ゲストも検索できる
