# Build 25: README・性能テスト

## やること

- README を整える（起動手順、Web UI と API の URL、Mailpit・MinIO の URL、テストの実行方法、API 仕様書の場所）
- API の仕様書（OpenAPI）を成果物として確定させる（エラーの返し方を含む）
- k6 などで、1年後の規模のデータ（投稿500万件・フォロー5,000人のユーザー）を投入する手順と、性能テストのシナリオを用意する（タイムライン・グローバルフィード・検索・単体ページ）
- 測定結果を ADR / `constraints` の更新材料としてまとめる。合格基準は、一覧と単体ページが p95 1 秒以内、検索が p95 3 秒以内。不合格のときは、`20261030-timeline-fan-out-on-read.md` の代替案を適用するビルドを追加提案する
