## 改善提案

### R-1: 行数の実測から生成物と一括整形を除く
- **状況**: Step 3 の `bp actual` の追加行数が、`pnpm-lock.yaml` と Biome の一括整形で膨らみ、実績 BP が見積もりから 7 離れた
- **指示内容**: なし（実績を集計して判明した）
- **提案**: `bp actual` が lockfile と、指定したパターン（生成物・一括整形）を除いて数えられるようにする。除外パターンを基準表の側に持つ
- **優先度**: Should
- **対象**: workflow
- **具体案**: 「BP の実績では、lockfile（`pnpm-lock.yaml`）と、フォーマッタ導入に伴う既存コードの一括整形は実装行数に数えない。数えた場合は乖離の要因にその内訳を書く」を instructions.md に追記する

### R-2: フォーマッタを導入するビルドでは、対象外パスを先に決める
- **状況**: Step 4 で Biome を導入して `pnpm format` を実行したところ、`docs/` の Markdown（ADR・設計差分・issue.md）が整形され、変更を取り消した
- **指示内容**: なし
- **提案**: フォーマッタ・リンターの導入時は、`docs/` と生成物を対象外にしてから初回の適用を行う
- **優先度**: Should
- **対象**: doc:conventions
- **具体案**: 「Biome の対象は TS/JSON のみ。`docs/`・`.claude/`・Markdown は対象外とする（設計ドキュメントを整形で書き換えない）」

## リポジトリ固有の学び（L-N）

### L-1: Biome 2 は Markdown も整形し、`.claude/worktrees` も走査する
- **再現条件**: `files.includes` を絞らず `biome check --write .` を実行する。`docs/**/*.md` の表の列幅が書き換わり、`.claude/worktrees/*` 配下のコピーも対象になる
- **影響**: 永続ドキュメント（ADR・設計差分）が意図せず変更される。lint が worktree 内の別コピーのエラー（svg の a11y など）で失敗する
- **回避策**: `biome.json` の `files.includes` に `!docs`・`!**/*.md`・`!.claude` を入れる
- **判明したビルド**: build-02
- **判明日**: 2026-10-30

### L-2: CI の db は公式 postgres サービスコンテナでは足りない
- **再現条件**: マイグレーション `0000_extensions.sql` が `CREATE EXTENSION pg_bigm` を実行する。pg_bigm を含まないイメージの db に対して `pnpm --filter api migrate` を実行する
- **影響**: マイグレーションが失敗する
- **回避策**: CI で `docker compose up -d --build --wait db` を使い、`docker/Dockerfile.db` をビルドする
- **判明したビルド**: build-02
- **判明日**: 2026-10-30
